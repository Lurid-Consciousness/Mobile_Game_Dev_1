# Ultimate Nature Pack

Creator: Quaternius

Source: https://quaternius.com/packs/ultimatenature.html

Download: https://quaternius.itch.io/150-lowpoly-nature-models

License: CC0 1.0 Universal; original License.txt included.

Added 2026-09-11: 150 original FBX models. Blender and OBJ duplicates were not imported. No scripts or scene changes are included.

For this woodland game, start with WoodLog, WoodLog_Moss, TreeStump, and green trees, bushes and rocks. Snow and desert variants are optional.

Unity must finish its asset refresh before these models are ready to use. In-editor materials and scale have not been verified. Use a separate visual child beneath existing gameplay roots; retain existing scripts and colliders. Use URP/Lit materials if imported materials render pink.

WoodLog is a visual model, not a pre-fractured physics asset. Build barricades from separate Rigidbody pieces connected with Fixed Joints.
